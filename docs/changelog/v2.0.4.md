## 新功能

- 插件市场新增 cctv-h5e（央视H5E解密服务）：央视频 tv.cctv.com 点播 hls_h5e 加密TS 与频道直播 cdrm 加密TS 解密为标准 MPEG-TS，三端二进制（win-x64 MSVC /MT 静态、linux-x64/arm64 zig musl 全静态），解密核心源自 letr007/CCTVVideoDownloader（GPLv3，CLI 扩展 --stream/--init-new-mode，修改版源码随包附带）
- 直播取流：v3 接口 auth-key 签名（md5）下发 manifest.hls_cdrm，17 个 CCTV 频道全通；解密前 PES 扫描自适应视频 PID；CDN 瞬时抖动指数退避重试×4
- 新增央视频演示源：9 个分类（直播 + 新闻联播/焦点访谈等 8 栏目），点播走 h5e 解密、直播频道入口列表走 cdrm 解密，客户端只访问主服务端口（源 proxy 门面 + base 回流，插件仅 127.0.0.1 通信）
- 新增红果果[短]源：红果短剧全自包含实现（不依赖 hongguo-bridge 插件）——字节系全套签名（x-gorgon/x-ladon/x-helios/x-medusa，SM3/变种MD5/自研哈希/手写protobuf/自定义AES变体）纯 JS 移植；播放 proxy_rule 进程内 CENC 流式解密（按 Range 分段 AES-CTR，免落盘首播秒开）；8 分类（短剧/真人剧/漫剧/AI剧+4榜单）、6 组筛选、5 档清晰度
- scripts/debug-source.mjs 源离线调试器增强：注入 axios/require 桩与方法 this 上下文（requestHost/orId），支持二级/lazy 等依赖 this 的方法离线调用
- AGENTS.md 沉淀三端二进制编译（zig c++ musl 静态 / MSVC /MT）与 cntv 解密对接实战经验

## 修复

- 全局 CATE_EXCLUDE 默认表移除「新闻」：误杀正常源的新闻类分类（央视频源「新闻联播/晚间新闻」被静默吞）
- 插件市场卡片 platformSupported 判定支持 platform-arch 键（win32-x64/linux-x64/linux-arm64 三端二进制插件此前显示"平台不支持"）
- 直播播放判定按频道 id 白名单而非 flag：壳子回传 vod_play_from 形态不可控（缺失/小写/改写）导致直播误入点播分支
- 代理播放 URL 补伪后缀 #.m3u8/#.ts：嗅探型播放器（仅认 URL 后缀的壳子）格式识别；直播 m3u8 丢弃头部半截切片改善起播
