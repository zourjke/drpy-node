## 其他

- 原代本增强，支持模式切换 `5575` 和 `7777`,原7777模式
- 需要自己开mediaGo,新的默认模式采用不夜加速，装逼壳直接起飞，无需外挂服务(多个壳子同时用可能会端口冲突，待验证)
- 设置中心-系统配置 增加 设置原代本类型，现在不设置就默认是不夜加速
- 设置中心-接口挂载 增加设置允许挂载jar,默认关闭，设置为1可以使用挂载配置里的jar
- 更换默认的epg地址
- 新增源 `iptv.js`
- 更新 `直播转点播[合].js` 支持配置文件自定义请求头
- 修复 `金牌影院.js`、新增源动力出品的 `短剧库.js`
- 修复ds猫视频不夜源 `黑木耳克隆|T4` 等一级筛选不讲规则返回的不是列表导致的兼容性问题
- ds猫支持不夜多线程磁盘加速
