## 新功能

- 管理界面「Instrument Panel」全站重构：暗色/亮色双主题、全新 UI 组件库与移动端适配，原生弹窗全部替换为统一的 Toast/Dialog 反馈体系
- 接口文档专业化：集成 Swagger UI，全部路由补齐 OpenAPI schema，文档由代码自动生成，与实际接口永不脱节
- 新增插件市场：从远程源一键安装/更新/卸载插件，支持 sha256 完整性校验、GitHub 加速兜底与安装进度实时展示
- 新增验证码识别代理：源直接请求主服务相同端口即可调用 captcha-bypass（ddddocr）插件的 OCR/滑块/旋转识别，无需感知插件端口
- 文件管理预览接入只读 monaco 编辑器，支持 40+ 种语言语法高亮，暗色/亮色主题跟随
- 站源映射新增「撤销修改」按钮，防止误保存

## 修复

- 修复 lx 音乐代理带参数请求被误杀中断、站源映射页面误报「未保存」等问题
- 访问 .env 等受保护文件的提示更加明确

## 优化

- 修复十余处内存与资源泄漏（定时器堆积、连接池失效、子进程孤儿、缓存无界增长等），长时间运行更稳定
- 大规模重构收敛：路径校验/流媒体重写/AI 对话等重复实现统一收敛，清理死代码与失效依赖，新增零依赖测试体系
