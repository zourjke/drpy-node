## 其他

- 更新网盘插件 `ali.js`,修正播放失败无法自动刷新cookie问题
- 更新 `至臻[盘].js` 支持原画播放
- 夸克支持原画播放，并优化夸克和uc自动刷新cookie逻辑
- `random-http-ua.js` 优化 `instanceof Array` 改为 `Array.isArray` 解决传递option无法生成ua问题
- drpyS源模块系统升级，支持使用`.cjs`的标准commonJS模块导入使用，运行读写文件等操作。示例`_lib.request.cjs`。谨慎使用，权限比较大
- 在源里的示例用法:
- ```javascript
- const fs = require('fs');
- const path = require('path');
- const absolutePath = path.resolve('./');
- console.log(absolutePath);
- const data = fs.readFileSync('./js/_360.js', 'utf8');
- console.log(data);
- const {getPublicIp1, getPublicIp2} = require('../js/_lib.request.cjs');
- console.log('typeof getPublicIp1:', typeof getPublicIp1);
- console.log('typeof getPublicIp2:', typeof getPublicIp2);
- ```
- drpyS源初始化增加30秒超时返回机制(但不会中断后台任务，请确保代码不要含有死循环等操作)
- 研究本地代理流但是没成功，代码保留了
