## 其他

- 新增猫爪专属订阅码设置，默认为all,设置中心-接口挂载可以配置猫爪订阅码
- 增加严格订阅码模式(启用此开关所有配置地址sub=没填或者不在已有订阅码中都无法访问，不启用则保持以前逻辑显示全部源)
- ds源写法更新，支持 `推荐` `一级` `搜索` 按字符串快捷写法同dr2
- 根目录 `plugin.example.js` 改名为 `.plugins.example.js`,`plugin.js` 改名为 `.plugins.js`,解决打包7z缺少plugin.js导致ds启动失败问题
