## 其他

- 目录结构调整，各个类型的源迁移到 spider目录
- 新增对json目录的文件修改监听功能，使得json目录变化立即生效无需重启
- 新增appGet系列模板
- 新增py文件自动生成配置(hipy_t3)
- 优化生成配置中的name，js优先取title,py取getName，最后取文件名
- 重构ds源require函数，现在引入相对目录的_lib可以直接写require(./_lib_xxx.js)
- 优化$函数的加载时点，更加规范，不再自调用
- pathLib新增readLib函数，可用于读取dr2目录下的_lib文件，无需fs.readPath
- 设置中心增加对PY源是否挂载的设置，默认挂载
