## 其他

- 移除过时的pinyin库(`pinyin` 库依赖的 `nodejieba` 跑路了)
- 同步 `秋秋` 提供的代码，主要涉及新增了 `node-forge` 库，优化了几个网盘工具类
- ds写源文档增加了对 `action` 交互动作的详细图片说明
- 首页配置接口链接增加动态密码注入，设置密码的场景不需要手动改?pwd=
- 配置文件生成的名称提供了选项，默认改回按文件名(可选按源里设置的名称)
- 通过全局监听器解决了由于部分源 如 `番薯动漫` 内的异步错误导致的进程崩溃问题
- 所有源增加文件头，用于后续加载过程快速生成配置,首次加载配置提速:`6500ms -> 120ms`
- 修改对应的加解密函数支持带文件头的源解密
- `getOriginalJs` 修改为异步函数
