## 新功能

- 插件体系新增 python 型 runtime（runtime: "python"）：插件目录内独立 .venv + pip install requirements（幂等），启动/重启 API 与安装管线均异步自动准备依赖；解释器解析 venv 优先、VIRTUAL_ENV 次之、系统 python/python3 兜底；启停/崩溃/日志与 node 型完全一致，市场卡片显示「Python 服务」徽标
- 全能代理新增自身回环链路支持与 `unified_proxy_self_redirect` 开关（后台「环境配置 → 代理设置」）：默认 0 服务端回环转发，1 时 302 直连自身内容接口（Location 按请求 Host 动态拼接，零转发开销、单层代理链），套娃 /unified-proxy 目标直接 400 防递归

## 案例

- 首个 python 型私有插件 hongguo-bridge（红果短剧签名/解密播放桥，Flask 9979）：`logs/hongguo-bridge-0.1.0.zip` 手动上传安装，规范见 docs/python-plugin-design.md；中文路径 zip 须 UTF-8 编码文件名（7z Windows 默认 GBK 会解出乱码目录）
