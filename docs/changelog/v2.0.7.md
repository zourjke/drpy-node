## 新功能

- bundle 版成为标准打包产物：`node package-clean.mjs -bundle`（npm: package-server-bundle），rolldown 把 index.js 静态启动图打成 minify 单文件 `dist/server.bundle.mjs` + 根入口 2 行 wrapper，解压即用、入口/启动命令/服务配置与树版完全一致；微型 node_modules 只装 4 个 external 包（swagger-ui/ws/两个 wasm 包）
- `-bundle -min` 变体：swagger-ui 内联进 bundle，node_modules 顶层 54→3，staging 双拷 swagger-ui static 资产保文档页完整（hack 依赖包内两种路径拼法，升级需复查）
- 出包自带沙箱全局自检硬门：sandbox-check.bundle 枚举 drpyS 两张全局表 97 项逐个 typeof 校验，任一 undefined 拒绝出包
- bundle 压缩格式与树版同语义：默认 7z（更小），`-z` 才出 zip；bundle-min 7z 实测 27.2MB（zip 34.0MB）

## 修复

- bundle 版首页/docs 页 500 "marked is not defined"：marked 也是 UMD 全局挂载型（controllers/root.js、docs.js side-effect 导入后裸用），补 marked-shim；自检门同步堵盲区——新增 SERVICE_UMD_GLOBALS 表覆盖沙箱两表之外的主服务 UMD 消费（沙箱自检 97→98 项）
- push_agent 推送网页链接改为交壳子嗅探播放（正版大站直连 parse:0 导致网页链接无法起播的问题）
- php 源大响应撞缓冲上限：execFile 改 spawn 流式收集并放开 memory_limit
- py BaseSpider 构造期禁走 self.log 虚分发：子类重写 log 引用 super 之后才赋值的属性时构造中断（资源管理.py 实锤 AttributeError: debug_mode），改模块级 _log 直调

## 优化

- Android(FUSE) 冷启动 boot→listen 实测 6.94s → 3.009s（K60U files/ext4，树版同法 4.298s）：单文件消灭 ESM 模块图解析 stat 风暴
- spider 沙箱 UMD 全局债清理：CryptoJS/JSEncrypt/pako/JSON5/jinja/NODERSA/gbkTool/randomUa 八个 UMD 全局挂载型模块 shim 挂回 globalThis（修复 bundle 下 /api/设置中心 CryptoJS is not defined）
- 根路径统一走 pathHelper.PROJECT_ROOT（controllers/web.js 与 admin backup/sub 控制器），支持 ROOT env 覆盖
- php 源代理能力统一：BaseSpider getProxyUrl() + localProxy 注入与 php -S 自感知
- 资源管理源优化：100w 数据量、根目录无法识别问题
- alist 不需要 gzip；去掉没意义的央视直播推荐
- 打包链去重：copyReleaseFiles（树版/bundle 版文件集单一事实源）、mountUmdGlobal（8 份 shim 公共挂载件）、rolldown alias 数据表

## 文档
