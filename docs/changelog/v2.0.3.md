## 新功能

- 源管理新增启用/停用：单行开关 + 勾选批量操作；停用源退出 /config 与订阅分发，healthy=0 全源检测仍覆盖；状态存 config/source-states.json（不入库不入分发包，缺失自动创建），新源默认启用
- 源验证拆分为两个功能：语法检查（毫秒级静态校验）与 接口全流程验证（服务端自调用源 /api 真实走 首页→分类→详情→搜索→可选播放，每步独立超时，返回状态/耗时/数据量，verdict 三级评分 healthy/partial/dead；dr2 源提示仅支持语法验证）
- 插件体系新增 python 型 runtime：插件目录内独立 .venv + pip 依赖管理（幂等异步管线），启停/日志/崩溃处理与 node 型一致；首个 python 插件案例 hongguo-bridge（红果短剧播放桥，支持 --port/APP_PORT 自定义端口）
- 文件管理支持创建/编辑/删除：托管目录（config、json 递归 + 根目录 json）限 json|js|txt|m3u|conf 五类；框架自带 40+ 文件受保护禁删（列表 🔒 标记）；编辑接入 monaco 高亮（PC 右栏与移动抽屉）
- 仪表盘 QUICK ACTIONS 改由侧边栏导航数据派生：顺序与项目数和侧边栏功能完全一致，后续导航增删自动同步

## 修复

- 修复 /unified-proxy SSRF 防护误拦自身回环链导致的播放 403：源 m3u8 重写地址指向本服务 /proxy 的合法链路放行（本机地址 + 自身端口），172. 私网段判定精确化为 172.16-172.31
- 修复 TVBox 壳子兼容回归：/api/:module 的 filter/quick/pg 参数恢复字符串语义并容纳任意附加参数、/parse 去掉 url required（此前壳子传 filter=true、空 pg 被 400 拒绝导致无法加载）
- READ_ONLY_MODE 全链路补口：/sources/upload、/sources/delete、/sources/enabled 接入只读检查（此前只读模式下源文件仍可增删）；文件管理新建/删除同样受只读约束
- 修复覆盖安装的 Windows 目录句柄问题：rename 自动重试 + 逐项搬空兜底（运行中插件停止后句柄延迟释放/杀软扫描锁定不再导致安装失败）
- 修复 hongguo-bridge 端口配置：--port 启动参数 > APP_PORT 环境变量 > config.json > 9979，解析组件与 Flask 主端口强制一致
- 修复 drpyS 沙箱 randomUa 未定义导致的启动失败（random-http-ua UMD 库改为默认导入）
- 修复 config.js / unified-proxy.js 文件头 /** 粘连导致的 log import 丢失；QUICK ACTIONS 等界面文案与行为一致性修正
